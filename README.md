# PinTop — macOS 窗口悬浮 / 并排工具

让任意 App 的某个窗口始终显示在其他窗口之上（镜像悬浮），或把它摆到屏幕指定位置（并排布局）。
提供菜单栏 App 和命令行两种用法，Swift 编写，不修改任何窗口内容。

## 方式一：菜单栏 App（推荐）
```bash
./build.sh                      # 生成 build/PinTop.app（同时生成命令行工具 ./pintop）
open build/PinTop.app           # 菜单栏出现图钉图标；也可把它拖进「应用程序」
```
点图钉图标：
- **镜像悬浮（当前桌面 / 所有桌面）** → 选择窗口，即开始悬浮；
- **并排布局** → 选择窗口 → 靠右/靠左/靠上/靠下的预设；
- **正在悬浮** → 逐个取消，或“取消全部悬浮”；
- **恢复被摆放窗口的位置**、**权限设置**（辅助功能 / 屏幕录制）、**退出**。

首次使用在 系统设置 → 隐私与安全性 里给 **PinTop** 授予「辅助功能」和「屏幕录制」（授权屏幕录制后需重新打开 PinTop）。
授权对象是 PinTop 本身，不再是终端。
> App 使用 ad-hoc 签名（无需开发者账号）：每次重新构建后，系统可能要求重新授权；若授权后仍无效，在设置里先移除再重新添加 PinTop。

## 方式二：命令行

```bash
./build.sh                 # 生成 ./pintop
./pintop                      # 交互式：选窗口 → 选模式
./pintop list                 # 列出窗口ID
./pintop float <ID>           # 镜像悬浮（当前桌面）
./pintop float <ID> --all     # 镜像悬浮（所有桌面，实验性）
./pintop dock <ID> --right 35%                       # 并排布局：靠右占 35%（--left/--top/--bottom，也可写像素）
./pintop dock <ID> --frame x,y,w,h                   # 任意区域
./pintop dock <ID> --right 35% --fit <ID2>,<ID3>     # 同时把其他窗口放进剩余区域
./pintop restore                                     # 恢复被 dock/fit 移动的窗口
```
悬浮模式按 Ctrl+C 退出，不遗留状态。

## 命令行授权（授权对象是运行它的终端 App）
- 系统设置 → 隐私与安全性 → **辅助功能**
- 镜像悬浮另需 **屏幕录制**（授权后重启终端）

## 镜像悬浮原理
macOS（SIP 开启）不允许第三方改变其他 App 窗口的层级：`AXRaise` 对后台 App 无效，`SLSOrderWindow` 被系统拒绝，
“前置 + 还焦点”会与被点击窗口互相抢占而闪动。因此采用镜像方案：
- 用 ScreenCaptureKit 捕获目标窗口，在最上层放一个无边框、不抢焦点的面板，与真窗口位置大小重合；
- 仅当目标窗口被其他窗口盖住时才显示镜像；未被盖住时隐藏，你操作的就是真窗口；
- 点击镜像：先激活真窗口，再把这次鼠标操作转发给它；之后打字走系统原生路径。拖动、滚动同样转发，可通过镜像移动/缩放窗口；
- 所有桌面模式（`--all`）：镜像面板出现在每个桌面，包括其他 App 的全屏桌面；
  真窗口在其他桌面/全屏桌面时，镜像是离开时刻的静态画面且只读（点击不转发，避免被系统带离当前桌面）；
  回到真窗口所在桌面后恢复实时并可操作。
- 推荐搭配：Dock 右键该 App →「选项 → 分配给 → 所有桌面」，这样在普通桌面里真窗口始终存在、可实时操作；全屏桌面则由镜像显示。

## 安全性
- 不注入代码、不改 SIP/系统设置、不读写窗口内容、不使用抢焦点的私有接口；
- 唯一非公开符号是 `_AXUIElementGetWindow`（只读，把 AX 窗口映射为窗口ID）；
- 只有 `dock --fit` 会改变其他 App 窗口的大小（默认不动），`restore` 可还原。

## 已知限制
- 镜像画面有轻微延迟；输入法候选框、悬停提示等细节可能与真窗口略有差异；
- 全屏窗口、固定大小窗口可能拒绝被调整（dock 模式会提示）。
